Proyectos destacados

Conoce las iniciativas tecnológicas desarrolladas por nuestros estudiantes.

BridgeSense IoT

Sensor IoT instalado en una maqueta de puente a escala para monitorear vibración, inclinación y esfuerzo estructural en tiempo real.

Sitio Web de Presentación

Desarrollo de una página web de presentación institucional, responsiva y con identidad visual propia.

Inventario de Bodega Funcional

Sistema funcional de control de inventario de bodega, con registro de entradas, salidas y stock en tiempo real.

Base de Datos de Inventario General

Modelo de base de datos para la gestión de inventario general, con relaciones entre productos, categorías y ubicaciones.

Brazo Robótico

Brazo robótico de bajo costo desarrollado para tareas de manipulación y clasificación de piezas.

Base de Datos Estructural UA

Diseño de una base de datos estructural relacionada con procesos y registros de la Universidad Autónoma.
